# Registration & Login Forms

A simple project with **Login and Registration forms** designed using **HTML, CSS, and Bootstrap**.

## 🚀 Features
### Login Form
- Email input  
- Password input  
- "Remember Me" checkbox  
- Submit button  

### Register Form
- Full Name  
- Email  
- Phone Number  
- Date of Birth  
- Password & Confirm Password  
- Gender (radio buttons or dropdown)  
- Submit (Register) button  

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- Bootstrap 5
