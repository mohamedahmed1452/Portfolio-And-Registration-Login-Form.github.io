# Portfolio Website

A simple and responsive portfolio website built using **HTML, CSS, and Bootstrap**.  
This project showcases personal information, skills, and sample work in a clean and modern design.

## 🚀 Features

- Responsive layout with Bootstrap grid system
- Sections for:
  - About Me
  - Skills
  - Projects
  - Contact
- Modern design with clean UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
