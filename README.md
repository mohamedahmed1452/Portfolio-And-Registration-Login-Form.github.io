🔒 Login & Registration Forms Project

This project contains Login and Registration forms built with HTML, CSS, and Bootstrap.
It demonstrates user authentication interfaces with a focus on responsive design and form validation.

✨ Features

Login Form – User authentication interface

Registration Form – New user registration with input validation

Form Validation – Basic checks for username, email, and password

Responsive Design – Works on desktop, tablet, and mobile using Bootstrap

🛠️ Built With

HTML5

CSS3

Bootstrap
